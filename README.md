# OrangeHRM 人力资源管理系统测试项目

## 项目简介

本项目基于开源人力资源管理系统 OrangeHRM 开展软件测试实践，主要围绕登录、员工管理、请假管理及招聘管理等核心业务模块进行测试。

通过本项目完成需求分析、测试用例设计、功能测试、接口测试、数据库验证、性能测试、缺陷管理及回归测试，并整理相关测试文档及测试结果。

## 测试范围

本项目主要覆盖以下模块：

- Login：登录与退出
- PIM：员工信息管理
- Leave：请假申请与审批
- Recruitment：招聘及候选人管理

## 测试内容

- 需求分析
- 功能测试
- 接口测试
- 数据库测试
- 性能测试
- 缺陷管理
- 回归测试
